# 林草智答 · 运行说明（轻量版）

一个基于你自己的林草规程文档的智能问答助手。上传文档、提问、得到答案和出处。

**本版本只依赖 Flask 一个库，安装快速、不需要编译，32 位或 64 位 Python 都能用。**

---

## 第 1 步：确认 Python 可用

打开命令行（按 Win + R，输入 cmd 回车），输入：

```
python --version
```

能显示版本号即可。若提示"不是内部或外部命令"，去 https://www.python.org/downloads/ 重新安装，安装时**务必勾选 Add python.exe to PATH**。

## 第 2 步：安装依赖

在这个文件夹里打开命令行（**在文件夹地址栏输入 cmd 回车**），执行：

```
python -m pip install -r requirements.txt -i https://mirrors.aliyun.com/pypi/simple/
```

只有一个小包，几秒钟就装完。

## 第 3 步：获取大模型 API Key

推荐阿里云百炼（通义千问）：

1. 打开 https://bailian.console.aliyun.com/ ，注册并登录。
2. 开通「通义千问」和「通用文本向量」服务（新用户有免费额度）。
3. 在控制台创建一个 API Key，复制备用（形如 sk-xxxxxx）。

## 第 4 步：启动

```
python app.py
```

看到提示后，浏览器打开：

```
http://127.0.0.1:5000
```

然后在页面里：左侧粘贴 API Key → 上传林草文档 → 点「构建知识库」→ 下方提问。

---

## 界面里能做什么

- 智能问答：根据上传的文档回答，并给出来源。
- 引用来源：每条答案都能展开看到命中的原文。
- 转人工：输入包含「投诉」「人工」等词时，自动提示转接人工。

## 常见问题

- **浏览器打不开**：确认命令行窗口没有关闭，且显示的是 http://127.0.0.1:5000。
- **报 401 或鉴权失败**：检查 API Key 是否完整，是否已在百炼开通服务。
- **构建时卡住**：文档很多时首次向量化会慢，属正常。
- **答案不准**：多为文档切分过粗，可把代码里 `split_text` 的 `size` 调小，如 300。
- **端口被占用**：把代码最后一行 `port=5000` 改成 `port=5001` 再启动。
