# 林草智答 · 运行说明

一个基于你自己的林草规程文档的智能问答助手。上传文档、提问、得到答案和出处。

不需要改代码，照着下面四步操作即可。

---

## 第 1 步：安装 Python

1. 打开官网 https://www.python.org/downloads/
2. 下载最新版 Python，安装时**务必勾选**「Add Python to PATH」。
3. 安装完成后，打开「命令提示符」（Windows）或「终端」（Mac），输入：

```
python --version
```

看到版本号（如 Python 3.12.x）就说明装好了。

## 第 2 步：安装依赖

在这个文件夹里打开命令行，然后执行：

```
pip install -r requirements.txt
```

如果 `pip` 不行，换成 `python -m pip install -r requirements.txt`。

> Windows 小技巧：在文件夹地址栏输入 cmd 回车，就能直接在该目录打开命令行。

## 第 3 步：获取大模型 API Key

推荐用阿里云百炼（通义千问）：

1. 打开 https://bailian.console.aliyun.com/ ，注册并登录。
2. 开通「通义千问」和「通用文本向量」服务（新用户有免费额度）。
3. 在控制台创建一个 API Key，复制备用（形如 `sk-xxxxxx`）。

> 也可以换用智谱、DeepSeek 等兼容 OpenAI 接口的服务，把界面里的接口地址和模型名改一下即可。

## 第 4 步：启动

在文件夹里执行：

```
streamlit run app.py
```

浏览器会自动打开一个页面（地址通常是 http://localhost:8501）。然后在页面里：

1. 左侧粘贴你的 API Key；
2. 上传林草规程、方案或手册文档（支持 Word、文本、Markdown）；
3. 点「构建知识库」；
4. 在下方对话框提问，例如「古树群如何认定？」。

---

## 界面里能做什么

- 智能问答：根据上传的文档回答，并给出来源。
- 引用来源：每条答案都能展开看到命中的原文。
- 转人工：输入包含「投诉」「人工」等词时，自动提示转接人工。

## 常见问题

- **提示找不到 streamlit**：说明第 2 步依赖没装成功，重跑一次安装命令。
- **回答报错 401 或鉴权失败**：检查 API Key 是否复制完整、是否已在百炼开通服务。
- **回答很慢**：文档很多时首次构建向量会慢一些，属于正常。
- **答案不准**：多为文档切分过粗，可把 `split_text` 里的 `size` 调小（如 300）。
