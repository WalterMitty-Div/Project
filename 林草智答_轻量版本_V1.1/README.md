# 林草智答 · 运行说明（v1.1）

一个基于你自己的林草规程文档的智能问答助手。上传文档、提问、得到答案和出处。

**支持两种模式：云端大模型（效果最好）与本地小模型（免费离线，适合外业无网）。**

---

## 一、准备（只做一次）

**1. 确认 Python 可用**
按 Win + R，输入 cmd 回车，执行：
```
python --version
```
能显示版本号即可。若提示"不是内部或外部命令"，去 https://www.python.org/downloads/ 重新安装，安装时**务必勾选 Add python.exe to PATH**。

**2. 安装依赖**
在项目文件夹里打开命令行（**在文件夹地址栏输入 cmd 回车**），执行：
```
python -m pip install -r requirements.txt -i https://mirrors.aliyun.com/pypi/simple/
```
只有一个小包，几秒钟装完。

## 二、启动

```
python app.py
```
看到提示后，浏览器打开 `http://127.0.0.1:5000`。

## 三、使用（按页面顺序）

**① 设置页**：选择模型模式。
- 选「云端大模型」，需填入 API Key（阿里云百炼获取，见下方）。
- 选「本地小模型」，无需 API Key，但要先装好 Ollama（见下方）。
- 选好后点「保存设置」。

**② 知识库页**：上传林草文档（支持 Word、文本、Markdown），点「构建知识库」。

**③ 聊天页**：提问，例如「古树群如何认定？」。答案下方可展开引用来源。

> 提示：切换向量模型后，需要回知识库页重新构建一次。

---

## 云端大模型怎么配

1. 打开 https://bailian.console.aliyun.com/ ，注册登录。
2. 开通「通义千问」和「通用文本向量」服务（新用户有免费额度）。
3. 创建 API Key，粘贴到设置页。

## 本地小模型怎么配

1. 打开 https://ollama.com/ 下载安装（Windows 一路下一步）。
2. 在命令行执行下面两条，拉取模型：
```
ollama pull qwen2.5:7b
ollama pull bge-m3
```
3. 在设置页选「本地小模型」，接口地址保持 `http://127.0.0.1:11434/v1` 即可。

> 内存建议：8G 内存可把模型换成更小的 `qwen2.5:3b`；16G 内存用 `qwen2.5:7b` 更流畅。

## 常见问题

- **浏览器打不开**：确认命令行窗口没关，且显示 http://127.0.0.1:5000。
- **云模式报 401**：检查 API Key 是否完整、服务是否已开通。
- **本地模式连不上**：确认 Ollama 已启动，且命令行里能用 `ollama list` 看到模型。
- **答案不准**：多为文档切分过粗，可把 app.py 里 `split_text` 的 `size` 调小，如 300。
- **端口被占用**：把 app.py 最后一行 `port=5000` 改成 5001。
